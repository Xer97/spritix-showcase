# Spritix 80-second product showcase

[![Watch the Spritix showcase](poster.jpg)](https://www.youtube.com/watch?v=S2-RTmRhgJ0)

[Watch on YouTube](https://www.youtube.com/watch?v=S2-RTmRhgJ0) · [Try Spritix](https://spritix.ai)

An edited introduction to creating 2D character animations with Spritix: character input, actions, directional animation, timing adjustments, and export formats. The Ember character outputs come from the product; the film arranges them into a designed presentation rather than an uncut screen recording or speed benchmark. The text-description opening illustrates an input option; Ember itself originated from an uploaded image.

- Duration: 80 seconds.
- Viewing: YouTube, using the same video as the Spritix homepage.
- Language: English on-screen text; music soundtrack.
- Poster: extracted from this exact video at 00:31.
