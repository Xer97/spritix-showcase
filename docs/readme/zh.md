## 关于 Spritix

使用 [AI 精灵图工具](https://spritix.ai/zh)，从角色全身参考图开始制作动画。[精灵图生成器](https://spritix.ai/zh)支持待机、行走、奔跑、跳跃和攻击五种动作。调整播放节奏与循环后，通过 [AI 精灵图集生成器](https://spritix.ai/zh)排列动画帧。[精灵图集制作工具](https://spritix.ai/zh)支持导出精灵图集、GIF、Atlas JSON 和独立 PNG 帧。

## 开始使用

1. 上传角色全身图，或通过文字描述创建角色。
2. 准备角色参考图，生成所需动作。
3. 预览动画，调整播放与导出设置，下载当前套餐允许的文件。
