### AI 精靈圖與 2D 角色動畫

從一個角色開始，逐步建立動作庫。Spritix 是面向獨立遊戲開發者、Game Jam 創作者和小型 2D 團隊的線上工作台。

## 關於 Spritix

使用 [AI 精靈圖工具](https://spritix.ai/zh-Hant)，從角色全身參考圖開始製作動畫。[精靈圖產生器](https://spritix.ai/zh-Hant)支援待機、行走、奔跑、跳躍和攻擊五種動作。調整播放節奏與循環後，透過 [AI 精靈圖集產生器](https://spritix.ai/zh-Hant)排列動畫影格。[精靈圖集製作工具](https://spritix.ai/zh-Hant)支援匯出精靈圖集、GIF、Atlas JSON 和獨立 PNG 影格。

## 開始使用

1. 上傳角色全身圖，或透過文字描述建立角色。
2. 準備角色參考圖，產生所需動作。
3. 預覽動畫，調整播放與匯出設定，下載目前方案允許的檔案。
