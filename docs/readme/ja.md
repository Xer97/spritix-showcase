## Spritix について

[スプライト AI ツール](https://spritix.ai/ja)で、キャラクターの全身参考画像からアニメーションを制作できます。[スプライト生成ツール](https://spritix.ai/ja)は待機、歩行、走行、ジャンプ、攻撃に対応。タイミングやループを調整し、[AI スプライトシート生成ツール](https://spritix.ai/ja)でフレームを配置します。[スプライトシート作成ツール](https://spritix.ai/ja)から、スプライトシート、GIF、Atlas JSON、個別の PNG フレームを書き出せます。

## 使い方

1. キャラクターの全身画像をアップロードするか、文章で新しいキャラクターを作成します。
2. 参考画像を準備し、必要なアクションを生成します。
3. アニメーションを確認し、再生と書き出しの設定を調整して、プランで利用できるファイルをダウンロードします。
