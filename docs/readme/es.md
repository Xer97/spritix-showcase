## Acerca de Spritix

Usa [IA para sprites](https://spritix.ai/es) para crear animaciones a partir de una imagen de cuerpo completo. El [generador de sprites](https://spritix.ai/es) admite reposo, caminar, correr, saltar y atacar. Ajusta el ritmo y los bucles y organiza los fotogramas con el [generador de sprite sheets con IA](https://spritix.ai/es). El [creador de sprite sheets](https://spritix.ai/es) exporta sprite sheets, GIF, Atlas JSON y fotogramas PNG individuales.

## Primeros pasos

1. Sube una imagen de cuerpo completo o describe un personaje nuevo.
2. Prepara la referencia del personaje y genera una acción.
3. Previsualiza la animación, ajusta la reproducción y la exportación y descarga los archivos disponibles en tu plan.
