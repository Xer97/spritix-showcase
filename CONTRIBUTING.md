# Contributing to Spritix Showcase

Share a reproducible example made with [Spritix](https://spritix.ai), improve an explanation, or correct a translation through a pull request.

## Case studies

Add a folder under `showcase/` with a short README, a preview, and any files you have permission to publish. Describe the character input, action, direction, relevant export settings, and any editing applied to the result. State the asset source and reuse permissions explicitly. Include only material you own or are authorized to share; remove account details and private information from captures.

Link the case from `showcase/README.md`. Keep large source projects outside this repository and link a release attachment when appropriate.

## Translations

The English README is the content reference. Translations live in `docs/readme/`; keep their language navigation and relative media links working. Use natural local terminology and link to the matching language on spritix.ai. Describe available features without guaranteeing output quality, generation time, or search rankings.

Submitting content does not change its existing license. Include any intended permission grant explicitly for review.
